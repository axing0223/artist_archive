# 画师库

一个**本地优先**的画师收藏夹：你的画师资料、标签、参考图都存在**你自己选的一个文件夹**里，
用普通 JSON 与图片文件保存，随时能在资源管理器里打开、备份、手工整理。

配套一个浏览器扩展「画师库 · 图片助手」，负责需要登录态才能做的事：抓 Danbooru 的作品与数量、
按需取原图、调 NovelAI 生成测试风格图、以及在任意网页上把选中的文字一键加进画师库。

## 30 秒上手

1. **装扩展**：`chrome://extensions` → 打开右上角**开发者模式** → **加载已解压的扩展程序** →
   选本仓库里的 **`图片取图扩展`** 文件夹。详见 [`图片取图扩展/安装与测试.md`](图片取图扩展/安装与测试.md)。
2. **打开画师库**：点浏览器工具栏上的扩展图标，就会在扩展页里打开画师库。
3. **选数据文件夹**：点页面顶部「打开资料库」，选中一个文件夹（空的会新建，已有的会读进来）。
4. 开始加画师：拖本地图片进去、或从 Danbooru 搜索添加。**数据从此都在你选的那个文件夹里。**

> 也可以不装扩展：直接双击仓库根目录的 **`画师库.html`**。
> 那条路需要额外打开扩展的「允许访问文件网址」，而且取图仍要扩展代发，所以推荐用扩展图标那条路。
> 两条路读写的是同一个数据文件夹，随你换着用。

## 能做什么

**画师卡片**——每位画师一张卡，卡片上是作品缩略图（默认 5 格，可调）、站点作品数量
（含"截至日期之前有多少"）、分类与标签、参考评分。卡片右上角那一排按钮从左到右是：
**删除、画师页面、刷新、画风拟合、书钉、编辑**。

- **刷新**：重新读站点上的正式名、笔名、作品数量与截至日期前数量，读完直接落盘。
- **画风拟合**：一个标记位——"这张参考图能代表画风"，标过之后可以一次性筛出来。
  它和「参考评分」是两件事：评分说的是多喜欢，这个说的是能不能代表画风。
- **书钉**：把卡片**钉在列表顶端浮动显示**，滚到哪儿都看得见。可以钉多张（一行一张往下排），
  浮动区能收起/展开，上限在设置里调（默认 3，1–12）。浮动区里放的就是原来那张完整卡片，
  **在浮动卡片里点「编辑」也会就地展开成编辑器**。
- **编辑**：就地展开成编辑器，改名字、分类、标签、链接、备注，增删作品格，点保存才写盘。

**整理与查找**

- **筛选**：四组分类与标签都是**三态**——不选 → 正选（只看这些）→ 反选（排除这些）。
  另有「特殊筛选」：无作品图、画风拟合。
- **搜索**：画师名、笔名、标签、备注一起搜，支持输入法组合期间不打断。
- **排序**：序号、名称、作品数量、评分等；**翻页与换排序不会把你的视线移走**。
- **管理分类与标签**：重命名、合并、删除，每一行直接显示有多少位画师在用。

**图片**

- **测试风格图**：和作品参考并排对比画风。可以导入本地图片，也可以用 NovelAI 批量生成。
- **查看器**：点缩略图看大图，支持原图 / 中图 / 缩略图逐级回退、键盘切换。
- **采集**：从 Danbooru 按画师名搜作品、逐张勾选加进来，或从任意网页右键加一位画师。

**其它**

- **本地优先**：数据是你自己选的一个文件夹里的普通 JSON 与图片，随时能在资源管理器里打开、
  备份、手工整理。**不联网也能用**（只有采集与生图需要联网）。
- **深浅主题**、**竖屏布局**、**紧凑/舒适两套视图**、**减少动态效果**跟随系统。

## 仓库里都有什么

| 路径 | 作用 |
|---|---|
| `app/` | **画师库的源码**（多文件那一份，扩展页加载的就是它）。要改代码改这里。 |
| `画师库.html` | 由 `app/` 打包出来的**单文件版**，双击即用，不需要本地服务。 |
| `图片取图扩展/` | 浏览器扩展（MV3）。`图片取图扩展/app/` 是构建生成的镜像，**不要手改**。 |
| `数据/` | 你的数据（**不进版本库**，`.gitignore` 已忽略）。要留档就直接复制整个文件夹。 |
| `工具/` | 独立的小工具页，例如 `回填作品.html`。 |
| `CHANGELOG.md` | 每个版本改了什么。 |

> 开发过程中还有几份材料**只留在作者本机**、不进版本库（`.gitignore` 里逐条列了名字）：
> 个人采集清单、发布前的验收记录、性能基线数字、待办清单。所以这个仓库里没有性能基线与验收记录，
> 但 `npm run test:*-performance` 这些脚本**都在**，跑出来的数字就是当时记进那几份文档的数字。

## 常用命令

```bash
npm test                 # 全部单元测试（新增测试文件要登记到 package.json）
npm run build            # 重新生成 画师库.html，并把 app/ 镜像进扩展目录
npm run test:browser     # 真实浏览器验收（需要 Chrome/Edge 与 Node.js 22+）
npm run test:ui          # 界面验收（含竖屏、窄窗、深浅主题、2000 位虚拟列表）
npm run test:pin-performance    # 书钉的交互与性能回归
npm run test:edit-performance   # 编辑保存的性能回归（真实浏览器 + OPFS）
npm run test:work-performance   # 作品增删的性能回归
npm run test:density-performance # 密度切换的逐帧回归
npm run test:bulk-performance   # 批量刷新、采集、测试图与导出的性能回归
```

**改完 `app/` 里的任何文件，先跑 `npm run build` 再重新加载扩展**——扩展里跑的是镜像，
`npm test` 里有一条用例会逐字节校验镜像与源码一致，忘了构建它会直接报错。

## 数据长什么样

```text
数据/
  画师库.json                  # 索引：画师顺序、分类与标签列表、几项设置
  画师/
    0001-画师tag-画师编号/
      信息.json                # 这位画师的全部资料（可读、可手工编辑）
      缩略图/                  # 页面与候选区用的图
      大图/                    # 只有你自己上传/勾选保存的原图才会写到这里
```
